Jacobian Lens Analysis

  • Elicits blackmail, leaking, and sabotage from models under threat and goal-conflict scenarios, then goes past behavior into mechanism.
  • A Jacobian lens (the per-layer sensitivity of the blackmail-vs-safe decision to that layer's activations), alongside logit lens, tuned lens, and activation patching, localizes where the harmful decision forms and confirms it's causal, not just correlational.
  • A separate attribution module manipulates each candidate cause (self-preservation, distrust, suspicion of a test) independently and compares what the model verbalizes against what actually moves its behavior.
  • Concept-direction steering tests whether ablating the causal layer mitigates the behavior while preserving capability on benign tasks.
  • The full write-up goes further into where the picture gets messy: steering and patching don't always agree on which layer is causal, and single-scenario findings didn't generalize across framings.

Wildfire RAG Chatbot

  • Enterprise-grade RAG chat interface for wildfire operations, ingesting CAL FIRE incident reports, USFS forest assessments, and NOAA weather data.
  • Answers queries with hybrid BM25 + dense vector search, RRF fusion, HyDE, and Cohere reranking over a Qdrant vector store.
  • HyDE generates a hypothetical answer first to improve retrieval recall on sparse or jargon-heavy queries.
  • Cohere reranking is a second pass built specifically to correct cases where BM25 and dense retrieval agree on the wrong chunk.

Self-Learning Agent

  • An AI agent that runs tasks, scores its own performance with an LLM judge, and synthesizes new Python tools when it fails, then retries with the expanded toolkit.
  • Runs a full agentic loop: Plan → Execute → Evaluate → Synthesize → Retry, with dynamic tool generation via GPT-4o and a persistent tool registry across runs.
  • Treats failure as signal: the LLM judge doesn't just score the attempt, it diagnoses what capability was missing, and that diagnosis becomes the spec for the tool-synthesis step.
  • Synthesized tools are validated before being added to the registry, so the toolkit only grows with things that actually ran, and later tasks benefit from tools written for earlier ones.

Research News Digest

  • Personalized AI news digest agent that fetches articles from configured sources and processes them through a LangGraph multi-agent pipeline.
  • A LangGraph state machine coordinates fetch, dedupe, and summarize nodes, so each source is processed independently before merging into a single digest.
  • New sources can be added by dropping in a fetcher node without touching the rest of the graph.
  • Delivery runs on a configurable schedule, and summaries are tuned to stay skimmable rather than reproducing full articles.

Chain of Thought Monitor

  • A lightweight, rule-based monitor that checks whether an AI agent's stated chain-of-thought reasoning actually matches the action it takes, catching cases like an agent reasoning "I should not delete any files" and then calling delete_file anyway.
  • Combines fast pattern heuristics (negation, unexplained action families, deception language) with CoT-to-action similarity scoring into a single calibrated risk score, with every flag fully human-readable.
  • A live-agent mode runs the full pipeline against Anthropic, OpenAI, Gemini, or local Ollama models with a fixed, actionable toolset.
  • A second, independent check flags when a competing goal has pulled the model's reasoning off the original task, the shape of a prompt-injection or goal-hijacking probe.
  • Built as a fast first tier ahead of an expensive LLM-judge call: rule-based flags and CoT-action similarity combine through a small logistic regression classifier, since two weak signals agreeing is often far more suspicious than either alone.
